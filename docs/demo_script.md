# 三分钟演示脚本

## 演示前

1. 清空小车前后左右至少1米通道。
2. 烧录主板和红外遥控板，CSK使用新版12命令固件。
3. 启动 `/home/ucar/PetCargo/tools/run_robot.sh`，网页确认STC在线、安全锁未锁定。

## 0:00–0:35：介绍STC电子宠物

介绍光敏、温度、震动、霍尔、ADXL345、OLED、数码管、LED、蜂鸣器、红外、EEPROM和双串口。网页展示实时光照、温度、情绪和三轴加速度折线。

## 0:35–1:15：离线语音四向运动

依次说“小爱同学，向前走”和“小爱同学，向左走”。说明CSK负责离线识别，STC产生500毫米动作请求，ROS按里程计闭环执行。

## 1:15–1:50：强光逃跑

用手电筒照射至数码管 `L` 值达到20。持续200毫秒后OLED变为害怕、蜂鸣器报警，小车后退约500毫米。网页环境图同时越过红色阈值线。

## 1:50–2:20：磁铁与音乐互动

磁铁靠近霍尔传感器，展示快乐上升与投喂计数；随后说“小爱同学，唱首歌”，展示Timer1驱动的非阻塞蜂鸣器曲目，并强调播放期间遥测仍持续更新。

## 2:20–2:50：第二块STC红外遥控

按住遥控板导航键的四个方向，小车对应点动；松开后300毫秒内停车。遮住红外发射端，演示租约失效自动归零。

## 2:50–3:00：安全收尾

网页点击急停，说明K3、网页、串口失联、里程计异常和红外租约均有独立停止路径。

## 故障替代

- OLED不亮：继续使用数码管、LED和蜂鸣器。
- 语音失败：使用第二块STC红外遥控演示运动。
- ROS或网络失败：只演示STC本地传感、情绪、音乐和显示。
- 强光未触发：确认数码管原始值达到20，不再执行两点校准。
