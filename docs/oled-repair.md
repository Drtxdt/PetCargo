# OLED 黑屏修订

本次仅修改 OLED 驱动及其测试，未改语音 SDK、按键、音乐或扫描器。

- 数据建立、SCL 高低阶段、START/STOP 和 ACK 时钟均增加显式等待，避免依赖编译器调用开销。
- 上电等待改为 200 ms 非阻塞时基；逐条初始化，不阻塞其他任务。
- 初始化前发送 9 个恢复时钟和 STOP。
- 明确设置起始行、对比度、RAM 显示模式和电荷泵；完整写入第一帧后开启显示。
- 保留 SSD1306、0x3C（写地址 0x78）、128×64、反相 ULN2003 接口与 16 字节刷新上限。

参考：[Solomon Systech SSD1306 数据手册](https://cdn-shop.adafruit.com/datasheets/SSD1306.pdf)，I²C 接口与初始化章节。新增的原生 C 测试执行实际 oled.c，检查数字总线帧、初始化等待与刷新大小；不模拟电压和上升沿。

## 烧录测试

1. 烧录 `firmware/stc/build/petcargo.hex`，参数仍为 11.0592 MHz、P5.4 普通 I/O。
2. 整板断电后重新上电，等待约 1 秒。SCK/SCL 仍接 SM S1，SDA 仍接 SM S2。
3. 若仍黑屏，烧录 `firmware/stc/build/petcargo_diagnostic.hex`；应出现边框及条纹固定测试图，数码管为 12345678。
4. 两份固件均无显示时，不应把数字协议测试通过视为 OLED 已连接成功。提供 OLED 正反面照片及模块链接，确认控制芯片/接口；有万用表时测 OLED VCC-GND 与静止时 SCK/SDA-GND 电压。

SM 经 ULN2003 的开集电极输出只能拉低，不能主动输出高电平；必须有到合适逻辑电源的上拉。先确认屏模块已有上拉与允许电压，**不要直接把信号接到 5V，也不要盲加到 5V 的上拉**。软件无法通过这两条单向线路读取 ACK 或检测高电平。SCK 标签本身不意味着接错，但也不能单凭标签判定控制芯片。
