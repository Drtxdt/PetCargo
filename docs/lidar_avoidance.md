# 激光雷达避障与实机校准

PetCargo订阅`/scan`并通过TF把`laser_frame`测距点转换到`base_link`。算法不使用地图或`move_base`，只对当前运动方向建立车体扫掠走廊。

## 默认参数

- 车体半长0.171米、半宽0.128米，走廊额外扩宽0.03米。
- 车壳净空0.35米开始减速，0.15米停止并在连续2帧确认后绕行；0.10米立即停止。
- 绕行轨迹为侧移0.40米、沿原方向0.50米、回移0.40米，速度不超过0.10米每秒；执行前必须验证三段完整扫掠区均安全。
- `/scan`或TF超过0.5秒不可用时，所有运动失败关闭。
- 每条离散命令或每次遥控按住最多绕行一次。绕行途中再次受阻即终止。

全部参数位于`ros/petcargo_ros/config/petcargo.yaml`。比赛仓库只作为构建和运行underlay，不会被修改。

## 启动检查

```bash
rostopic hz /scan
rosrun tf tf_echo base_link laser_frame
rostopic echo /petcargo/lidar_status
```

网页必须显示“雷达工作正常”后才允许测试运动。若外部已经启动YDLidar，用`run_robot.sh`的第四个参数`false`避免重复启动节点。

## 首次校准

1. 架空车轮或将小车置于至少2米见方的空地，验证网页雷达为在线。
2. 把平整纸箱分别放在车体前、后、左、右，测量车壳到纸箱的实际距离。
3. 当实际距离约0.15米时，网页显示的方向净空应在0.10至0.20米之间；超出时先修正TF，不用阈值掩盖安装偏差。
4. 低速测试四个方向的减速和停车，再测试单次三段绕行。
5. 两侧同时放置障碍，确认小车停车并报告`obstacle_blocked`。
6. 绕行过程中松开遥控键、切换方向并点击网页急停，均应立即输出零速度。

强光逃跑只使用雷达防撞，不自动绕行。障碍存在时本地OLED和蜂鸣器反馈仍保留，但运动结果为`OBSTACLE_BLOCKED`。
