# PetCargo 双板红外遥控器

## 板卡分工

- 主板烧录 `firmware/stc/build/petcargo.hex`，使用板载 `P3.6/IR_RXD` 接收红外。
- 遥控板烧录 `firmware/stc_remote/build/petcargo_remote.hex`，使用板载 `P3.7/IR_TXD` 发射红外。
- 两块板之间没有导线，不需要共地；各自由 USB 供电。
- 时钟均选择 **11.0592 MHz**。

## 导航键 ADC 区间

| 操作 | ADC 8 位范围 | 红外命令 |
|---|---:|---:|
| Key3 | 0–28 | 保留，不发送方向 |
| 右 | 29–76 | `0x04` |
| 下 | 77–116 | `0x02` |
| 中心 | 117–156 | `0x05` 停止 |
| 左 | 157–188 | `0x03` |
| 上 | 189–228 | `0x01` |
| 松开 | 229–255 | `0x00`，连续两帧 |

按住方向时每 100 ms 重发完整帧。主板把每个有效方向帧转换成速度 `0.12 m/s`、租约 300 ms 的 `JOG_REQUEST`。红外被遮挡或按键松开后，租约超时会自动输出零速度。

## NEC 帧

完整帧按 `address, ~address, command, ~command` 发送：

```text
0x50 0xAF command ~command
```

主板同时校验地址反码和命令反码。有效命令为前 `01`、后 `02`、左 `03`、右 `04`、停止 `05`、松开 `00`。收到红外方向会立即取消语音或强光触发的离散运动，直到租约到期。

## 烧录与检查

```powershell
cd firmware\stc_remote
.\build.bat
```

烧录后先脱离小车检查数码管：应分别显示 `UP`、`DOWN`、`LEFT`、`RIGHT`、`STOP`。再让两板红外器件相对，在网页确认运动来源显示为“红外”，最后遮挡接收端，确认 300 ms 内停止。
