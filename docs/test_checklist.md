# 联调与验收清单

## 主板

- [ ] 主固件冷启动20次，数码管、LED和OLED均正常刷新。
- [ ] K1短按循环四页；K2短按睡眠、长按播放或停止音乐；K3锁定与长按解除急停。
- [ ] `L=19`不触发；`L≥20`保持200毫秒触发；`L≤15`保持2秒重新武装。
- [ ] 强光、震动、温度和磁铁分别改变预期情绪及OLED图案。
- [ ] 音乐播放时遥测、CSK接收和K3急停仍正常。

## 语音

- [ ] 12条命令各测试20次，识别成功至少18次。
- [ ] 前、后、左、右均移动 `0.5±0.15 m`。
- [ ] “停下来”取消动作但不锁定下一条命令。
- [ ] 强光外部触发播报正常；若平台不支持，蜂鸣器与OLED降级链路正常。

## Windows USB遥控板

- [ ] 上、下、左、右和中心键ADC区间正确，松开显示空闲。
- [ ] 按住方向每100毫秒续租，四个方向均正确。
- [ ] 松开、拔掉遥控板USB、退出Windows程序或网络中断后租约使小车归零。
- [ ] 遥控输入能立即取消正在执行的语音动作。
- [ ] 串口帧头、版本或异或校验错误时Windows桥不转发。

## ROS与网页

- [ ] 协议v1帧被拒绝，v2遥测、事件、动作、点动均可解析。
- [ ] `/cmd_vel`仅由safety_gateway发布，横移使用 `linear.y`。
- [ ] 串口或里程计超过500毫秒未更新时动作停止。
- [ ] `/scan`与TF均正常时网页显示雷达在线；任一超过500毫秒不可用时拒绝所有移动。
- [ ] 四向走廊只响应路径内障碍；15厘米净空连续2帧进入避障，10厘米立即停车。
- [ ] 选边同时检查侧移、越过和回归三段扫掠区；任一段不足15厘米时不得选择该侧。
- [ ] 纸箱避障完成350毫米侧移、400毫米越过、350毫米回归；空间不足或第二个障碍立即终止。
- [ ] 遥控绕行时松开或换向，300毫秒内归零且不继续自主绕行。
- [ ] 强光后退遇障只停车；转圈在膨胀车体范围有障碍时被拒绝。
- [ ] 网页无大头、运输模式和烦躁值；三组折线各保持最多300点。
- [ ] 网页、K3急停保持锁定，解除前拒绝所有运动。
- [ ] 连续运行30分钟无复位、串口死锁、ROS退出或网页历史无限增长。

## 仓库边界

- [ ] 主板与遥控板HEX均由SDCC构建，时钟11.0592 MHz。
- [ ] 比赛仓库工作区与实施前一致，无PetCargo文件。
